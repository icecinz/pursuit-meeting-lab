# 追及与相遇 · 直线运动实验室

一个用于高中物理教学的互动演示，通过动画和图像观察两个物体在直线运动中的追及与相遇。

## 使用

- 下载整个仓库后，直接用浏览器打开 `追及与相遇演示.html`，无需联网。
- `downloads` 目录提供 Mac 和 Windows 大屏版程序包，包内附有使用说明。程序包中的网页与此仓库的离线网页一致。
- 选择同向追及、相向相遇或通用模式，调整初始位置、速度和加速度；播放或拖动进度条，观察运动、位置—时间图和速度—时间图。
- 点击「分类图谱」查看情境分类；在「设置」中调整字号和基础情境显示。

页面已检查宽屏和窄屏排版；尚未在希沃设备上实机测试。Mac 和 Windows 程序包的跨设备运行情况也需在目标电脑上确认。

## 文件与构建

`index.html`、CSS 和 JavaScript 文件是可编辑的源码；`dist/index.html` 和 `追及与相遇演示.html` 是构建出的单文件网页。修改源码后，在本目录运行：

```sh
python3 build.py
```

脚本会重新生成这两个单文件网页。程序包需要另行更新，不会由此脚本自动生成。
