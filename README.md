# 追及与相遇 · 直线运动实验室

**当前版本：1.0**

一个用于高中物理教学的互动演示，通过动画和图像观察两个物体在直线运动中的追及与相遇。

## 使用

- 下载整个仓库后，直接用浏览器打开 `追及与相遇演示.html`，无需联网。
- `downloads` 目录提供 Mac 和 Windows 1.0 程序包，包内附有使用说明。程序包中的网页与此仓库的离线网页一致。
- 从「常用预设」「更多情境」或「自由设置」进入，调整参数，播放或拖动进度条，观察运动、位置—时间图和速度—时间图。
- 「更多情境」可按运动方向、两车运动方式和例子选择，并按结果筛选；「分类图谱」可以跳转到相应例子。

## 1.0 说明

当前包含五个常用主题，并提供更多分类情境和自由设置。两车减速相向的情境目前包含双方停下仍未相遇的例子，另两类临界比较尚未加入。

已检查主题切换、情境筛选和图谱跳转，以及宽屏和窄屏排版；尚未在希沃设备上实机测试。Mac 和 Windows 程序包也尚未在目标电脑上实机双击验证。

## 文件与构建

`index.html`、CSS 和 JavaScript 文件是可编辑的源码；`dist/index.html` 和 `追及与相遇演示.html` 是构建出的单文件网页。修改源码后，在本目录运行：

```sh
python3 build.py
```

脚本会重新生成这两个单文件网页。程序包需要另行更新，不会由此脚本自动生成。
